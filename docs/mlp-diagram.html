What one neuron does

Each of the 64 neurons in hidden layer 1 does the same small calculation on all 17 inputs, with its own weights. Training adjusts those weights so that useful patterns, such as many failed logins together with a poor IP reputation, produce a large positive sum.

From logit to probability

The last layer gives one unbounded score, the logit. The sigmoid squeezes any logit into a probability between 0 and 1, and the app maps that probability to a risk level.

Training versus prediction

The same network behaves slightly differently while it learns (notebook §12) and when it scores sessions (§14, the API and the dashboard).
